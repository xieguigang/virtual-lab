# 2026-10-26

## 新增 humanoid_robot 白色人形机器人模型（models/humanoid_robot/）

为虚拟实验室提供"采购硬件前的虚拟替身"：74 DOF、1.70 m、47.7 kg、每手 19 关节。

**产出**
- `humanoid_robot.glb`：整机 76 node / 61 mesh / 2 material（3.3 MB，Y-up，顶点在 link 局部系）
- `humanoid_robot.urdf`：76 link / 75 joint，引用 `meshes/*.obj`（61 个）+ 共用 `robot.mtl`
- `poses.json`：rest / pen_grip / pen_write / cook_stir / fold_blanket
- `build/`：geom / parts / model / export / build_all / preview / verify 七个脚本，可参数化重建

**关键决策**
- 采用"全解析曲面"路线（球 / 胶囊 / 超椭球 superbox 参数化生成），不依赖任何第三方几何库；
  `geom.py` 里 `build_surface()` 定死"环按 z 递增、逆时针朝外"的绕序，焊接后统一算法线。
- 与工程既有 `GlbLinkLoader.vb` 对接的三个约定：Y-up `(x,z,-y)`、顶点存 link 局部系、
  node 名 = URDF link 名、node 层次 = 关节树。实测该加载器对 link 自身节点算出 nodeToLink=单位阵，
  所以顶点必须是局部坐标（这一点用 `six_axis_arm.glb` 反推确认过）。
- `base_link` 用 fixed 关节接 pelvis（默认焊在地面，适合固定工位动作），文档给了改浮动基座的方法。

**踩过的坑（重要，下次直接复用）**
- 本项目约定 **+X 前 / +Y 左**，`prim_superbox(a,b,c)` 的 a 是 X（进深）、b 是 Y（横向），
  写躯干尺寸时极易把宽深写反；`m_trans`/`prim_capsule` 的参数也是 (x,y,z) 顺序，
  肩、髋、锁骨三处都曾把横向偏移写进 X 轴，表现为"零件飘在身体前方"。
- GLB 的 JSON chunk 必须用 **0x20 空格**填充（不是 0x00），否则 `json.loads` 与
  System.Text.Json 都可能报 "Extra data"。
- 写 URDF 时局部变量 `ext` 会覆盖函数参数 `ext`（mesh 后缀），导致文件名变成
  `meshes/pelvis(0.2, 0.33, 0.31)`。
- 纯标准库软件渲染器（`preview.py`）出图约 8~10 s/张（820×1050，2× 超采样），
  是校核几何最有效的手段：调对相机前先确认 +X/+Y 语义，否则会误判成"模型被压扁"。

**自检**：`python build/verify.py`（URDF 树结构 / mesh 存在性 / GLB 顶点往返 / 节点世界位置
与 FK 一致性 / 足底贴地 / 姿态关节名），当前全部通过，顶点偏差 5e-9 m。

## 追加：科幻化改造（同日晚）

材质从 2 种扩到 4 种：`robot_white` / `robot_visor` / `robot_glow`（青 0.18,0.88,1.00，
自发光 ×3.0）/ `robot_graphite`（0.070 石墨）。新增配件：胸口能量核心、面罩发光眼线、
头顶导流鳍、太阳穴灯、体侧散热口、背脊导光条、腰环、肩球光环 + 机甲肩盖、
四肢导光条、肘/膝/踝发光环、石墨鞋底。三顶点数 141k → 174k。

**这一轮新踩的坑**
- 胶囊 `prim_capsule` 的两端是**半球封头**，表面会比端点再外凸一个半径 —— 做"圆盘/透镜"类
  贴面件时端点必须回退 radius，否则会戳出壳体一大截（胸口核心最初就是一个外凸黑球）。
- 装饰件与母体曲面**近相切**会产生锯齿状 z-fighting（髋轭 vs 大腿根、掌背横条 vs 手指）。
  规则：护套/光环半径至少比母体大 **1.5 mm**，或者干脆明显放大一档，不要停在 0.5 mm。
- 细导光条贴在**双向弯曲**的曲面上（如腹部）会断成虚线，改成圆形透镜更稳。
- glTF 的 `emissiveFactor` 必须 ≤1，超过要用 `KHR_materials_emissive_strength` 扩展；
  MTL 的 `Ke` 也不要超过 1。
- 软件渲染器加了自制 bloom（1/8 分辨率三次盒式模糊回叠），强度按 `strength*2.2` 放大，
  0.3 左右合适，1.25 会整片过曝。
